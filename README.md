# Hoyafilm Portfolio

사진 중심의 반응형 정적 포트폴리오. 외부 라이브러리나 빌드 과정 없이 동작합니다.

## 미리보기

이 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000`을 엽니다.

## GitHub Pages

저장소 루트에 이 폴더의 내용을 업로드합니다. GitHub Settings → Pages에서 Deploy from a branch, main, /(root)를 선택합니다. 모든 경로는 상대 경로이므로 프로젝트 사이트에서도 사용할 수 있습니다.

## 내용 수정

- `index.html`: 소개, 작품 제목, 메뉴
- `style.css`: 화면 구성과 색상
- `script.js`: 확대 보기의 사진 목록
- `assets/`: 사진과 로고
